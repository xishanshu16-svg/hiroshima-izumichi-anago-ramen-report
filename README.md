# 出道 鉄砲町店｜穴子ラーメン Instagram Reels Research

広島グルメ系Instagramアカウント4件の公開リール510件を確認し、ラーメン系で伸びている投稿と、出道 鉄砲町店の「夜の魚屋直営居酒屋から昼の穴子ラーメンへ」というPR設計をまとめた単一HTMLダッシュボードです。

## Local preview

`public/index.html` をブラウザで開くか、Wranglerでプレビューできます。

## Deploy

```sh
npx wrangler deploy
```

穴子ラーメンは公開メニューで「黒道」「白道」各850円、ライスセット1,000円、自家製穴子粉末と5種トッピングを確認済みです。ランチの提供曜日・時間・当日の販売状況は公開前に店舗確認が必要です。
