# 出道 広島駅店｜穴子ラーメン Instagram Reels Research

広島グルメ系Instagramアカウント4件の公開リール510件を確認し、ラーメン系で伸びている投稿と、出道の「夜の海鮮居酒屋から昼の穴子ラーメンへ」というPR設計をまとめた単一HTMLダッシュボードです。

## Local preview

`public/index.html` をブラウザで開くか、Wranglerでプレビューできます。

## Deploy

```sh
npx wrangler deploy
```

商品価格・ランチ提供時間・穴子の調理仕様は公開情報で確認できていないため、公開前に店舗確認が必要です。
